# CatlabPing 📱

CatlabPing 是一款专为 **AstrBot** 设计的伴侣型 Android 应用。它可以通过安卓系统的底层服务，在后台静默收集设备信息，并自动上报给服务端的各类插件。

> ## 🔴 隐私与安全警告（必读）
>
> **CatlabPing 会采集以下高度敏感的个人隐私数据：**
> - 📸 **手机屏幕截图**（可能包含聊天记录、银行信息、密码等）
> - 📱 **App 使用记录**（完整的应用使用轨迹）
> - 📍 **GPS 定位数据**（实时位置信息）
>
> ### ⚠️ 部署安全要求
> **AstrBot 服务端及其插件必须部署在你自己完全掌控的设备上：**
> - ✅ 你自己的电脑（本地部署）
> - ✅ 你自己购买的云服务器（如腾讯云、阿里云）
> - ❌ **严禁**部署在他人服务器上——服务器管理员可以查看你的所有截图、位置和使用记录
> - ❌ **严禁**使用共享服务器或来路不明的托管服务
>
> ### ⚠️ 使用伦理
> 本应用设计初衷是**情侣/亲密关系间的趣味互动工具**，使用前提是**双方知情且完全自愿同意**。
> **严禁**在未经设备所有者明确同意的情况下安装或使用本应用进行非法的隐蔽监控。

## 🌟 核心功能 (v3.4.2)

目前应用包含三个完全解耦、可独立配置的核心功能模块：

### 1. 📍 位置查岗
- 实时获取设备的精确定位。
- 在后台定期（自定义间隔）上报当前位置。
- 设置家坐标与警报距离，离家超过距离可触发特殊逻辑。

### 2. 📱 手机使用监控
- 统计并上报当前前台正在使用的 App 和屏幕状态。
- （可选）支持截取屏幕并推送。

### 3. 💖 心率自动监听 (原生 BLE 直连)
- **原生 GATT 协议解析 (BLE 直连)**：深度集成 Android `BluetoothLeScanner`，可自动扫描周边设备，直接建立 GATT 连接并订阅标准心率服务 (UUID `180D`) 及其特征值 (`2A37`)。**彻底摆脱对 "Notify for Mi Band" 等第三方 App 的依赖**，实现最高效、稳定且毫秒级的后台数据拉取。
- **动态扫描与定点连接**：支持在设置页填入指定的设备 MAC 地址进行精准直连；若留空，则自动在后台搜索并捕获开启了“心率广播”特性的智能穿戴设备。
- **广播拦截后备方案**：同时保留了原有的 Android 系统广播拦截机制，全面兼容原生小米运动健康 (Mi Fitness)、Zepp Life 的广播 (`com.mc.xiaomi.heartRate` 等)。
- **省电优化与自动重连**：内置断线自动重连与超时重试机制。深度优化服务生命周期，仅在开启主开关且勾选直连时唤醒 BLE 扫描。心率值 (BPM) 提取后会在后台静默通过 OkHttp 发送给 AstrBot 专属的心率接收端。

## 🚀 升级与配置指南 (v3.3.x -> v3.4.0)

从旧版本升级到 v3.4.0 后，你会发现主界面进行了极大的重构，使用体验更清爽：

### 1. 独立的心率配置模块
原来混杂在“位置查岗”中的心率服务器设置现已被彻底分离。
**升级后你需要做的是**：
1. 打开应用，你会看到主页新增的 **💖 心率自动监听** 卡片。
2. 点击右侧的 **设置** 按钮，进入专属配置页。
3. 填入你的公网 AstrBot 心跳服务地址（例如：`http://your-ip:3476`）。如果留空，它会聪明地退回去读取位置查岗里的 IP。
4. **配置手环/手表接入方式（二选一）**：
   - **方式A（推荐：BLE直连）**：开启“直接连接 BLE 设备”开关，填入设备的蓝牙 MAC 地址（留空则自动寻找附近具备心率广播的设备，不限制小米，支持心率广播的华为手表等也可连接）。
   - **方式B（广播拦截）**：保持直连开关关闭，并确保手机上的运动健康 App (如小米运动健康、Zepp Life 等) 已开启心率广播分享。
5. 保存返回后，打开卡片上的总开关即可。

### 2. 完全绕过代理的网络模块
针对国内开发者和 Clash 用户，应用的 Gradle 环境已被深度优化。
- 全面移除了局域网代理的强依赖，转为全局注入 **阿里云 (Aliyun) 官方镜像源**。
- `SSL peer shut down incorrectly` 和握手超时问题已被彻底消灭。

## 📱 安卓权限设置（重要）

为确保位置查岗、屏幕监控及 **心率自动监听** 等后台服务不被系统杀死，请务必进行以下设置：

### 小米 / Redmi (HyperOS)
- 设置 → 应用设置 → 应用管理 → 搜索 CatlabPing
- 省电策略 → 改为「**无限制**」
- 自启动 → **开启**
- 应用联网 → 确保 WiFi、移动数据、后台联网全部开启

### OPPO / realme (ColorOS)
- 设置 → 电池 → 更多电池设置 → 优化电池使用 → CatlabPing → **不优化**
- 设置 → 应用管理 → CatlabPing → 耗电管理 → **允许后台运行**

### 华为 (HarmonyOS)
- 设置 → 电池 → 启动管理 → CatlabPing → **手动管理**（允许自启动、后台活动、关联启动）
